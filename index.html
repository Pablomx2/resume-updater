Resume Updater

Film & television credits
One-page tool

A film resume lives or dies on fitting one page. This is a single HTML file that edits the credit list, sizes the type and columns to fill exactly one sheet, and tells you when the list has outgrown the page.

No install, no build step, no server, no internet. The app ships empty — drop in an existing resume with Import HTML and it picks up the contact line, every section and credit, and the logo off that file. Or start blank, type, and upload your own logo.

Open the app How it works

Runs entirely in your browser. Nothing is uploaded anywhere, and no resume is stored in this repository.

What it does

Fits one page, exactly

Binary-searches the largest credit text size that still fits US Letter. The header never shrinks, and the type is capped at the original design size — it will not blow the resume up just to fill space.

Sizes the columns itself

Measures every project title and production-company string, then picks the three column widths that produce the fewest wrapped lines — rechecked at the fitted text size, since the two interact. Disagree? Drag the dividers on the sheet, or move the text-size slider.

Says when to cut

Grades readability, works out how many credits to drop to get back to comfortable type, and ranks the weakest lines: non-lead positions, entries that wrap, entries with no producer or director, repeated clients.

Five looks, or your own

Classic, Slate, Warm, Noir, Plain — then pick paper, text and accent yourself. The rest of the palette is derived from those, so a hand-picked pair stays coherent. The look is written into the export and read back on import.

Brings its own logo

No logo ships with the app. Importing a resume lifts the lockup image out of that file, or upload a PNG, JPG or SVG yourself. It travels with every export from then on.

Never deletes anything

Hide a credit to test a shorter list without losing it — it stays in the exported file too, carried in the data but printed nowhere. Pin one so the advisor leaves it alone. Drag to reorder, across sections. Edits autosave to your own browser and go nowhere else.

The problem it solves

How it works

  1. Open resume-updater.html in any browser, then Import HTML… to load a resume — one exported from this app, or the original bundled artifact download. Start a blank resume sets up the usual sections if you would rather type.
  2. Edit. Change any field and the preview refits instantly. New credits land at the top of their section, where the newest job belongs. Drag the ⠿ handle to reorder one, including into another section.
  3. Override it if you want. Hover the sheet and drag either column divider, or move the text-size slider. Each switches the matching automatic off; tick the checkbox to hand control back.
  4. Read the advice. The panel grades the page and names the specific lines worth cutting. Hide takes one out of the running without deleting it.
  5. Export or print. Export HTML asks where to save, then writes a clean standalone resume with the fitted numbers baked in — still hand-editable, still re-importable. Print / PDF prints just the sheet.

Buttons

Import HTMLReads a resume in — one exported here, or the original bundled artifact download. Brings the logo with it.
Export HTMLAsks where to save, then writes a standalone resume with the fitted column widths and text size baked in. Firefox and Safari have no save picker, so there it goes straight to Downloads.
Print / PDFPrints the sheet alone. Choose US Letter, margins None, headers and footers off.
ClearEmpties the editor and starts over.

Edits autosave to the browser's local storage, which is per-browser and per-machine. Use Export HTML for anything you want to keep or send.

Building it

resume-updater.html is generated. To change the app itself, edit src/app.template.html and run node src/build.js. src/seed.json is the state the app starts in — deliberately empty, so neither a resume nor a logo lives in this repository.
